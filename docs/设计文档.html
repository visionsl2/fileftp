赛博网盘 设计文档

文件上传下载浏览系统 - 技术架构与设计说明

V2.0.0

1. 系统概述

赛博网盘 是一个基于 Node.js + Express + MongoDB 的文件管理系统，提供以下核心功能：

  • 用户认证 - 注册、登录、登出，支持 JWT Token 和 Session 双重认证
  • 文件上传 - 单文件/多文件上传，实时进度显示，支持大文件分片上传
  • 文件下载 - 流式传输，支持中文文件名，RFC 5987标准编码
  • 文件浏览 - 仿Windows资源管理器风格，网格/列表视图切换
  • 图片预览 - 真正的缩略图生成（sharp），点击可放大查看，支持下载
  • 拖拽上传 - 拖拽文件到页面任意位置直接上传
  • 文件名重命名 - 已上传文件支持修改名称
  • 文件移动 - 多选文件+拖拽到文件夹移动，支持批量移动
  • 文件分享 - 生成分享链接，支持设置过期时间和访问密码
  • 文件夹管理 - 创建、重命名、删除，支持层级目录结构
  • 数据隔离 - 用户只能访问自己的文件，确保隐私安全
  • 安全过滤 - 黑名单机制，禁止上传危险文件类型
  • 开放API - RESTful API，支持第三方系统集成
  • 可配置存储 - 支持任意磁盘路径存储文件

3. 数据库设计

3.1 数据模型概览

模型集合名说明关联
Userusers用户账户信息-
Filefiles文件元数据owner → User, folder → Folder
Folderfolders文件夹目录owner → User, parent → Folder

3.2 User 用户模型

User {
  _id: ObjectId,
  username: String,          // 用户名（唯一）
  email: String,             // 邮箱（唯一）
  password: String,          // 密码（bcrypt加密）
  apiToken: String,          // API访问令牌
  apiTokenExpires: Date,     // API Token过期时间
  storageQuota: Number,      // 存储配额（默认1GB）
  storageUsed: Number,       // 已使用空间
  isActive: Boolean,         // 账号状态
  lastLogin: Date,           // 最后登录时间
  createdAt: Date,           // 创建时间
  updatedAt: Date            // 更新时间
}

3.3 File 文件模型

File {
  _id: ObjectId,
  filename: String,          // 存储文件名（唯一）
  originalName: String,        // 原始文件名
  mimeType: String,           // MIME类型
  extension: String,          // 文件扩展名
  size: Number,               // 文件大小（字节）
  storage: {
    path: String              // 物理文件路径
  },
  folder: ObjectId,          // 所属文件夹（null为根目录）
  owner: ObjectId,           // 所有者（必填，数据隔离）
  upload: {
    complete: Boolean,        // 是否完成
    chunksTotal: Number,      // 总分片数
    chunksUploaded: Number     // 已上传分片数
  },
  stats: {
    downloads: Number,        // 下载次数
    lastDownload: Date        // 最后下载时间
  },
  isDeleted: Boolean,         // 软删除标志
  deletedAt: Date,            // 删除时间
  createdAt: Date,
  updatedAt: Date
}

3.4 Folder 文件夹模型

Folder {
  _id: ObjectId,
  name: String,               // 文件夹名称
  parent: ObjectId,          // 父文件夹（null为根目录）
  owner: ObjectId,            // 所有者
  path: String,               // 完整路径（如 /images/photos）
  depth: Number,              // 层级深度（根=0）
  order: Number,              // 排序权重
  isDeleted: Boolean,         // 软删除标志
  createdAt: Date,
  updatedAt: Date
}

4. 安全机制

4.1 认证机制

多方式认证支持：

  1. Bearer Token - Authorization: Bearer <token>
  2. Cookie - 自动读取 token cookie
  3. Session - 基于 express-session

JWT 配置：

  • 签名算法：HS256
  • 过期时间：7天（可配置）
  • 存储内容：userId, username

4.2 文件安全过滤

系统采用黑名单机制，禁止上传以下危险文件类型：

类别扩展名
脚本语言.js, .ts, .py, .php, .asp, .jsp, .rb, .pl
Shell脚本.sh, .bash, .zsh, .bat, .cmd, .ps1
可执行文件.exe, .dll, .com, .scr, .msi, .vbs
服务器配置.htaccess, .htpasswd, .sql, .reg
其他.jar, .war, .go, .rs, .c, .cpp

4.3 数据隔离

每个用户只能访问自己的文件：

// 所有查询都强制添加owner条件
File.find({ owner: userId, ... })
Folder.find({ owner: userId, ... })
