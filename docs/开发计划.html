赛博网盘 - 文件上传下载浏览系统

技术栈: Node.js + Express + MongoDB

创建日期: 2026-05-18

V2.0.0

项目概述

一个完整的文件管理系统，支持Web端和移动端浏览，包含用户认证、文件上传下载、文件夹管理、开放API等功能。

技术方案

项目技术选型
后端框架Node.js + Express
数据库MongoDB
模板引擎EJS (前后端不分离)
认证方式JWT + Session
文件上传Multer

功能模块

1. 用户认证系统

已完成
  • 用户注册 (用户名、邮箱、密码)
  • 用户登录 (JWT Token + Session)
  • 退出登录
  • 登录限流保护

2. 文件上传

已完成
  • 单文件/多文件上传
  • 上传进度条显示
  • 存储配额限制
  • 文件夹归属

3. 文件安全过滤

已完成

禁止上传以下类型的危险文件:

脚本类: .js, .ts, .py, .php, .asp, .jsp, .rb, .sh, .bat
可执行: .exe, .dll, .com, .scr, .msi, .vbs
其他: .htaccess, .sql, .reg

4. 文件浏览器

已完成
  • 仿Windows文件浏览器风格
  • 网格视图/列表视图切换
  • 文件夹导航(面包屑)
  • 文件/文件夹图标
  • PC端和移动端响应式适配

5. 文件夹管理

已完成
  • 创建文件夹
  • 重命名文件夹
  • 删除文件夹(含内部文件)
  • 层级目录结构

6. 开放API

已完成
方法路径说明
POST/api/v1/auth/token获取API Token
POST/api/v1/files/upload上传文件
GET/api/v1/files获取文件列表
GET/api/v1/files/:id/info获取文件信息
GET/api/v1/files/:id/download下载文件
DELETE/api/v1/files/:id删除文件

7. 图片缩略图预览

已完成
  • 图片文件显示真实缩略图
  • 点击缩略图弹出预览模态框
  • 模态框支持下载功能
  • 支持 jpg/png/gif/webp 等格式

8. 拖拽上传

已完成
  • 拖拽文件到页面任意位置上传
  • 支持单个或批量文件
  • 拖拽区域视觉反馈
  • 进度条正常显示

9. 可配置存储路径

已完成
  • 通过 UPLOAD_DIR 环境变量配置
  • 支持 Windows 绝对路径 (D:/uploads)
  • 支持 Linux 绝对路径 (/data/uploads)
  • 支持相对路径 (./uploads)

数据库模型

User (用户)

username: String (唯一)
email: String (唯一)
password: String (加密存储)
apiToken: String
apiTokenExpires: Date
storageQuota: Number (默认1GB)
storageUsed: Number
isActive: Boolean
lastLogin: Date

File (文件)

filename: String (存储文件名)
originalName: String (原始文件名)
mimeType: String
extension: String
size: Number
storage.path: String (文件路径)
folder: ObjectId (所属文件夹)
owner: ObjectId (所有者用户)
upload.complete: Boolean
stats.downloads: Number
isDeleted: Boolean (软删除)

Folder (文件夹)

name: String
parent: ObjectId (父文件夹)
owner: ObjectId (所有者)
path: String (路径)
depth: Number (层级)
isDeleted: Boolean
