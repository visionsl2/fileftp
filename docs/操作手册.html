FileFTP 操作手册

文件管理系统的日常使用指南

V1.1

1. 快速入门

1.1 登录系统

1

打开浏览器，访问 http://localhost:3000

2

输入注册时的邮箱和密码

3

点击"登录"按钮进入文件管理器

提示： 如果忘记密码，需要联系管理员重置或重新注册账号。

2. 文件管理

2.1 上传文件

单文件/多文件上传

  1. 点击工具栏的 上传 按钮
  2. 在弹出的文件选择框中，选择要上传的文件（可多选）
  3. 点击"打开"开始上传
  4. 上传进度会显示在右下角的面板中
  5. 上传完成后，页面自动刷新显示新文件
支持的文件类型： 图片、视频、音频、文档、压缩包等常见文件格式。
禁止上传的文件： .js, .py, .php, .asp, .exe, .bat 等脚本和可执行文件，以保护系统安全。

2.2 下载文件

下载单个文件

  1. 在文件列表中找到要下载的文件
  2. 点击文件右侧的 下载图标
  3. 浏览器将自动下载文件到本地

2.3 删除文件

删除文件

  1. 在文件列表中找到要删除的文件
  2. 点击文件右侧的 删除图标
  3. 在弹出的确认框中点击"确定"
  4. 文件将被移至回收站（软删除）

3. 文件夹管理

3.1 创建文件夹

  1. 点击工具栏的 新建文件夹 按钮
  2. 在弹出的对话框中输入文件夹名称
  3. 点击"确定"创建

3.2 进入文件夹

  1. 找到要进入的文件夹
  2. 单击文件夹图标
  3. 页面将显示该文件夹内的内容
  4. 面包屑导航会显示当前位置

3.3 返回上级目录

  1. 点击面包屑导航中的 全部文件 返回根目录
  2. 点击面包屑中的任意上级文件夹名称可直接跳转

3.4 上传文件到指定文件夹

  1. 先进入目标文件夹
  2. 再点击 上传 按钮
  3. 上传的文件将保存在当前文件夹中

3.5 重命名文件夹

  1. 点击文件夹右侧的 铅笔图标
  2. 在弹出的对话框中输入新名称
  3. 点击"确定"完成重命名

3.6 删除文件夹

  1. 点击文件夹右侧的 垃圾桶图标
  2. 在确认对话框中点击"确定"
注意： 删除文件夹时，文件夹内的所有文件和子文件夹也会被删除。

4. 视图切换

网格视图 vs 列表视图

  • 网格视图： 以图标形式展示，适合浏览大量文件
  • 列表视图： 以表格形式展示，显示文件大小和修改时间

点击工具栏右侧的视图切换按钮即可切换。

5. 存储空间

查看存储使用情况

登录后，页面右上角显示当前存储使用情况：

已用: 12.5 MB / 1.0 GB
  • 默认每个用户有 1GB 存储空间
  • 删除文件会释放相应空间
  • 如果存储空间不足，需要删除一些文件

6. 账号管理

6.1 退出登录

  1. 点击页面右上角的 退出 按钮
  2. 系统将清除登录状态并跳转到登录页

6.2 注册新账号

  1. 在登录页面点击 立即注册 链接
  2. 填写用户名、邮箱、密码
  3. 确认密码（与密码相同）
  4. 点击"注册"完成

7. 常见问题

问题解决方案
上传失败，提示"存储空间不足"删除一些不需要的文件释放空间
上传失败，提示"禁止上传该类型文件"脚本类、可执行文件不允许上传
文件名为乱码这是浏览器编码问题，不影响文件内容
无法登录检查邮箱密码是否正确，联系管理员
文件夹点不开刷新页面后重试，或检查浏览器控制台

操作方法
刷新页面点击工具栏的刷新按钮 F5
返回根目录点击面包屑的"全部文件"
