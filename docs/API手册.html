赛博网盘 API 手册

开放API接口文档 - 供第三方系统集成使用

V2.0.1

1. 概述

赛博网盘 提供 RESTful API，允许第三方系统通过 API 访问用户的文件资源。

1.1 基础信息

项目值
API版本v1
基础URLhttp://localhost:3000/api/v1
数据格式JSON
编码UTF-8

1.2 认证方式

API 使用 Token 认证，支持三种方式：

方式一：X-API-Token Header（推荐）
X-API-Token: your-api-token
方式二：Authorization Header
Authorization: Bearer your-api-token
方式三：Query参数
/api/v1/files?api_token=your-api-token
提示： Token 通过 /api/v1/auth/token 接口获取，有效期1年。

2. 认证接口

POST /api/v1/auth/token

获取API访问令牌（Token）

请求头

Content-Type: application/json

请求体

{
  "email": "user@example.com",
  "password": "your-password"
}
参数类型必填说明
emailstring是用户邮箱
passwordstring是用户密码

成功响应

{
  "success": true,
  "token": "abc123...",
  "expiresAt": "2027-05-18T00:00:00.000Z",
  "message": "API Token获取成功，请妥善保存"
}

错误响应

{
  "success": false,
  "error": "INVALID_CREDENTIALS",
  "message": "邮箱或密码错误"
}

3. 文件接口

POST /api/v1/files/upload

上传文件到用户空间

请求头

Content-Type: multipart/form-data
X-API-Token: your-api-token

表单参数

参数类型必填说明
fileFile是要上传的文件（二进制）
folderstring否目标文件夹ID

成功响应

{
  "success": true,
  "file": {
    "id": "60f1a2b3c4d5e6f7a8b9c0d1",
    "name": "document.pdf",
    "size": 1024000,
    "type": "application/pdf",
    "extension": ".pdf",
    "createdAt": "2026-05-18T10:30:00.000Z"
  }
}

cURL 示例

curl -X POST http://localhost:3000/api/v1/files/upload \
  -H "X-API-Token: your-api-token" \
  -F "file=@document.pdf" \
  -F "folder=60f1a2b3c4d5e6f7a8b9c0d0"

GET /api/v1/files/:id/download

下载文件

路径参数

参数类型说明

响应

直接返回文件二进制内容，响应头包含：

Content-Type: application/pdf

cURL 示例

  -H "X-API-Token: your-api-token"

5. 使用示例

5.1 Python 调用示例

import requests

BASE_URL = "http://localhost:3000/api/v1"

# 1. 获取 Token
auth_response = requests.post(
    f"{BASE_URL}/auth/token",
    json={"email": "user@example.com", "password": "password"}
)
token = auth_response.json()["token"]
headers = {"X-API-Token": token}

# 2. 上传文件
with open("document.pdf", "rb") as f:
    files = {"file": f}
    upload_response = requests.post(
        f"{BASE_URL}/files/upload",
        headers=headers,
        files=files
    )
print(upload_response.json())

# 3. 获取文件列表
list_response = requests.get(
    f"{BASE_URL}/files",
    headers=headers
)
print(list_response.json())

# 4. 下载文件
file_id = upload_response.json()["file"]["id"]
download_response = requests.get(
    f"{BASE_URL}/files/{file_id}/download",
    headers=headers
)
with open("downloaded.pdf", "wb") as f:
    f.write(download_response.content)

# 5. 删除文件
delete_response = requests.delete(
    f"{BASE_URL}/files/{file_id}",
    headers=headers
)
print(delete_response.json())

5.2 JavaScript 调用示例

const BASE_URL = 'http://localhost:3000/api/v1';
const API_TOKEN = 'your-api-token';

const headers = {
  'X-API-Token': API_TOKEN
};

// 上传文件
async function uploadFile(file) {
  const formData = new FormData();
  formData.append('file', file);

  const response = await fetch(`${BASE_URL}/files/upload`, {
    method: 'POST',
    headers,
    body: formData
  });
  return response.json();
}

// 获取文件列表
async function listFiles() {
  const response = await fetch(`${BASE_URL}/files`, { headers });
  return response.json();
}

// 下载文件
async function downloadFile(fileId) {
  const response = await fetch(`${BASE_URL}/files/${fileId}/download`, { headers });
  const blob = await response.blob();
  const url = window.URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = '';
  a.click();
}

// 删除文件
async function deleteFile(fileId) {
  const response = await fetch(`${BASE_URL}/files/${fileId}`, {
    method: 'DELETE',
    headers
  });
  return response.json();
}

        HttpURLConnection conn = (HttpURLConnection) url.openConnection();

        body.put("email", email);
        body.put("password", password);

            os.write(body.toString().getBytes());
        }

        BufferedReader br = new BufferedReader(new InputStreamReader(conn.getInputStream()));

单文件大小100MB可通过配置修改
