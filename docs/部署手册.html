赛博网盘 部署手册

从零开始在服务器上部署 赛博网盘 系统

V2.0.1

1. 环境要求

软件依赖

软件最低版本说明
Node.js16.x 或更高JavaScript 运行时
MongoDB4.4 或更高数据库服务
npm8.x 或更高包管理器（Node.js自带）
ffmpeg（可选）4.x 或更高视频缩略图生成、视频 AI 分析

可选的 AI 大模型配置

配置项说明示例值
AI_PROVIDERAI 提供商openai
AI_BASE_URLAPI 地址https://api.openai.com/v1
AI_API_KEYAPI 密钥sk-xxxx
AI_MODEL模型名称gpt-4o / claude-3-5-sonnet / minimax-M3
AI_MONTHLY_LIMIT普通用户月限额（文件数）20
FFMPEG_PATHffmpeg 可执行文件路径/usr/bin/ffmpeg

不配置大模型时，系统自动使用本地 TensorFlow.js MobileNet 模型（离线可用，准确度较低）。

推荐环境： Ubuntu 22.04 / CentOS 8 / Windows Server 2019

2. 安装步骤

2.1 安装 Node.js

Ubuntu / Debian

# 使用 NodeSource 安装 Node.js 18.x
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node --version
npm --version

CentOS / RHEL

# 使用 NodeSource 安装 Node.js 18.x
curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash -
sudo yum install -y nodejs

# 验证安装
node --version
npm --version

Windows

从 Node.js 官网 下载安装包，一路下一步安装即可。

2.2 安装 MongoDB

Ubuntu

# 导入 MongoDB GPG 密钥
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -

# 添加 MongoDB 源
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list

# 安装 MongoDB
sudo apt-get update
sudo apt-get install -y mongodb-org

# 启动 MongoDB
sudo systemctl start mongod
sudo systemctl enable mongod

Windows

从 MongoDB 下载中心 下载 MSI 安装包，安装为 Windows 服务。

2.3 部署应用

步骤 1: 获取代码

# 克隆或下载项目代码
git clone <repository-url> /path/to/fileftp
cd /path/to/fileftp

步骤 2: 安装依赖

npm install

步骤 3: 配置环境变量

创建 .env 文件：

# 服务配置
PORT=3000
NODE_ENV=production

# MongoDB配置
MONGODB_URI=mongodb://localhost:27017/fileftp

# JWT配置（请修改为随机字符串）
JWT_SECRET=your-super-secret-key-change-this
JWT_EXPIRES_IN=7d

# 上传配置 - 支持任意磁盘路径
# Windows示例: D:/uploads 或 E:\FileFTP\uploads
# Linux示例: /home/user/uploads 或 /data/fileftp/uploads
# 相对路径会相对于项目根目录
UPLOAD_DIR=./uploads

MAX_FILE_SIZE=104857600
MAX_CHUNK_SIZE=5242880
MAX_FILES_PER_REQUEST=10

# 存储配额（字节）
DEFAULT_STORAGE_QUOTA=1073741824

# Session配置（请修改为随机字符串）
SESSION_SECRET=session-secret-change-this
存储路径说明： UPLOAD_DIR 支持绝对路径和相对路径。
  • Windows: D:/uploads 或 E:\FileFTP\uploads
  • Linux: /home/user/uploads 或 /data/fileftp
  • 相对路径: ./uploads 相对于项目根目录

步骤 4: 创建上传目录

# 如果使用相对路径
mkdir -p uploads
chmod 755 uploads

# 如果使用自定义路径（如Linux）
mkdir -p /data/fileftp/uploads
chmod 755 /data/fileftp/uploads
chown -R www-data:www-data /data/fileftp

步骤 5: 启动服务

# 开发模式
npm run dev

# 生产模式
npm start
启动成功！ 访问 http://localhost:3000 查看应用。

3. 生产环境配置

3.1 使用 PM2 进程管理器

# 安装 PM2
npm install -g pm2

# 启动应用
pm2 start server.js --name fileftp

# 设置开机自启
pm2 save
pm2 startup

# 查看状态
pm2 status fileftp

# 查看日志
pm2 logs fileftp

3.2 Nginx 反向代理配置

# /etc/nginx/sites-available/fileftp
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 0;  # 不限制上传大小（或用具体值如 10G）

    # 上传大文件需要长超时（视频等可能耗时数分钟）
    client_body_timeout 600s;
    proxy_read_timeout 600s;
    proxy_send_timeout 600s;
    proxy_connect_timeout 600s;

    # 禁用缓冲，直接流式传输到 Node.js
    proxy_request_buffering off;
    proxy_buffering off;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
HTTPS 配置： 生产环境务必配置 HTTPS，可使用 Let's Encrypt 免费证书。

3.3 配置 MongoDB 认证（推荐）

# 连接到 MongoDB
mongosh

# 切换到 admin 数据库
use admin

# 创建管理员账号
db.createUser({
  user: "admin",
  pwd: "your-password",
  roles: [{ role: "root", db: "admin" }]
})

# 退出
exit

# 修改 /etc/mongod.conf 启用认证
# security:
#   authorization: enabled

# 重启 MongoDB
sudo systemctl restart mongod

# 更新 .env 中的连接字符串
MONGODB_URI=mongodb://admin:your-password@localhost:27017/fileftp?authSource=admin

4. 防火墙配置

# Ubuntu (UFW)
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw enable

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --reload

6. 备份策略

6.1 备份 MongoDB 数据

# 创建备份脚本 /opt/backup/mongodb-backup.sh
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=/opt/backup/mongodb
mongodump --out=$BACKUP_DIR/backup_$DATE

# 保留最近7天的备份
find $BACKUP_DIR -type d -mtime +7 -exec rm -rf {} \;

# 添加定时任务
crontab -e
# 每天凌晨3点执行备份
0 3 * * * /opt/backup/mongodb-backup.sh

6.2 备份上传文件

# 创建备份脚本 /opt/backup/files-backup.sh
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
tar -czf /opt/backup/files/files_$DATE.tar.gz /path/to/fileftp/uploads

# 保留最近7天的备份
find /opt/backup/files -type f -mtime +7 -delete

8. 故障排查

问题解决方案
端口被占用修改 .env 中的 PORT，或 kill 占用进程
MongoDB 连接失败检查 MongoDB 服务状态和连接字符串
上传文件失败检查 uploads 目录权限
502 Bad Gateway检查 Nginx 配置和后端服务状态
内存溢出增加 Node.js 内存限制：node --max-old-space-size=2048 server.js
